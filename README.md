One technical distinction: malloc is a memory-allocation function in programming, and rainbow tables are lookup structures commonly associated with password-hash attacks. For an artistic system, you can reinterpret these as allocating a canvas or memory grid and looking up color or texture values; the artistic mapping is your own design.
